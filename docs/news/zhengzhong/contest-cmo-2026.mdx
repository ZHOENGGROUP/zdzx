# 数赛折桂

## 我校香桐书院学子入选数学奥赛省队

近日，2026 年全国中学生数学奥林匹克竞赛（省级赛区）成绩揭晓，我校学子赛场亮剑，斩获佳绩。

![](https://cdn.luogu.com.cn/upload/image_hosting/k63yixb1.webp)

我校香桐书院高三年级王若帆同学，以扎实深厚的数理功底、严谨缜密的逻辑思维与从容沉稳的赛场心态，勇夺一等奖，成功入选河北省数学竞赛省队，刷新我校学科竞赛历史纪录。河北省数学竞赛省队，代表省内中学生数学竞技的最高水平，是对青年学子学科素养、创新思维与综合实力的权威肯定。高二年级杨科旭同学在本次赛事中沉着应战，于重重考验之下稳扎稳打，充分展现了自身扎实的学科功底与良好竞技心态，赛场之上风采卓然，同样斩获一等奖。

![](https://cdn.luogu.com.cn/upload/image_hosting/h9e1bo63.webp)  
高三年级王若帆同学

![](https://cdn.luogu.com.cn/upload/image_hosting/grsf93jy.webp)  
高二年级杨科旭同学

斐然成绩的背后，离不开竞赛教练李龙老师的深耕与托举。集训中，他紧跟竞赛前沿，精心规划培优方案，实施分层教学、精准辅导，在日常训练中打磨学生解题思维、锤炼竞技心态，凭借专业坚守引路，助力学子攻坚克难，勇攀数理高峰。

荣光非一日而至，这份收获，是师生朝夕伏案、研思不辍的厚积薄发，更是我校香桐书院拔尖人才培养体系孕育出的累累硕果。多年来，学校锚定拔尖创新人才培养目标，精心构筑香桐书院成长沃土，持续夯实资源保障、创新思维培育与高端引领体系，为学子打造立体化、开放式的成长寰宇。今后，我校将持续深耕精育，聚力赋能，不断做强书院式育人模式，拓宽青年学子成长之路，培育更多拔尖创新人才，矢志办好人民满意的教育。
